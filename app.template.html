Typing shortcuts in Write mode

At the start of a line, type # + space for a title, ## for a heading, - or * for a bullet, 1. for a numbered list, [ ] for a checkbox, > for a quote, ``` for a code block, or --- for a divider. Everything is saved as clean Markdown.

Pasting from an AI chat

Paste raw Markdown into Write mode and Edith renders it as formatting instead of showing the symbols. Pasting from Google Docs or Word keeps its formatting too. To send text back, use File → Copy as Markdown (for AI tools) or Copy as formatted text (for Docs, Slack, email).

Notes

Select some text and press ⌘⇧M to attach a note. Notes live in the sidebar, in page order; click one to jump back to its text. Switch on Beside the page at the top of the Notes panel to see each note next to its passage as well. They are kept by Edith itself (with plain-text backups in its data folder), never inside your .md files, so a file stays clean wherever you send it. Deleted notes wait under Recently deleted for 90 days. “Save a .md copy with notes” is there if you ever want them in a file.

Write notes naturally; there is nothing to sort. Copy as prompt (also under File → Export, ⇧⌘R) turns every open note into one message for an AI chat, in page order, and tells the AI to judge each one: answer questions first, make clear edits, leave alone anything you said works. If you want to be explicit, choose Mark as a question or keep-as-is when writing a note.

Versions

Every save and import is kept as a version, plus an automatic one every 10 minutes while you're editing. Open History to compare any version with the current text, or restore it.

Saving

Autosave writes into the file you opened — there is no separate autosave file. Until a document has been saved once, nothing is autosaved; a recovery draft is kept instead and offered back to you if the app closes unexpectedly.
